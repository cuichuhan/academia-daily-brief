# Academia Daily Brief

金融学 UTD24 顶刊（F4重点） + 经济学五大顶刊 + 学者动态 + 会议/CFP/热点信号 + 6个信息源，每日自动生成的学术日报。

- 由 Claude 云端 routine 每天北京时间 04:00 自动生成并提交到本仓库 `reports/YYYY-MM-DD.html`
- 每天北京时间 08:00 自动推送摘要卡片到飞书
- 本地副本通过 launchd 定时 `git pull` 同步

## 查看某一天的报告

在浏览器中打开对应文件即可（GitHub 会直接渲染源码，建议用 [htmlpreview.github.io](https://htmlpreview.github.io/) 包一层来正常渲染页面样式），例如：

```
https://htmlpreview.github.io/?https://raw.githubusercontent.com/cuichuhan/academia-daily-brief/main/reports/2026-07-29.html
```

## 目录结构

```
reports/
  2026-07-29.html   一天一份，文件名为该报告的生成日期
```

## 数据说明

所有内容均来自公开网页检索（期刊官网 Advance Articles / Crossref 元数据 / NBER / SSRN / arXiv / 会议官网等），如实标注找不到或无法确认的信息，不编造作者、机构、方法或结论。LinkedIn 板块因无 API 访问权限，覆盖率有限，已在报告内注明。
